# Libron

The four desktop TrueType styles (`Regular`, `Bold`, `Italic`, `Bold Italic`) come from [Libron v0.32](https://github.com/nicoverbruggen/libron/releases/tag/v0.32), downloaded from the [Libron desktop release archive](https://github.com/nicoverbruggen/libron/releases/download/v0.32/Libron.zip).

The fonts are licensed under the SIL Open Font License 1.1. See `LICENSE.txt`. Source hashes are recorded in `provenance.json`.
