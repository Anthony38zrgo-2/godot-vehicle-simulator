# surfaces — shared rolling and tire slip bank

Source truth: manifest.json; regenerate with python -m tools.audio.cmr4_surfaces extract / prepare / verify. Original decrypted WAVs and config roles live in sounds/bank_sources/cmr4/surfaces. Keep filenames, source hashes and processing provenance. Runtime uses exterior samples only, at native PCM16 mono 22050 Hz. Loops have a baked 120 ms crossfade; do not apply another runtime crossfade. Sand/rumble are legacy fallback assets. Snow, ice, mud, mul and special events remain inactive until the scenario identifies them.
